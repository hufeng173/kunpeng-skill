# 音频蒸馏

## 范围

处理播客、访谈、旁白、演讲、配音、音乐结构、音效设计和独立音轨。视频中的声音仍由视频流程处理；需要深挖声音体系时再读取本文件。

## 本地证据

```bash
python scripts/kunpeng.py probe --profile audio
python scripts/kunpeng.py audio <音频或目录> --output <证据目录>
python scripts/kunpeng.py prepare-review <证据目录/manifest.json> --output <复核目录>
```

完全离线且已准备本地模型缓存时，为 `audio` 增加 `--offline`；可用 `--whisper-model <本地目录>` 和 `--model-cache <缓存目录>` 固定模型来源。

分析器输出流信息、单声道分析音频、响度、动态范围、节拍候选、停顿、频谱、过零率、音高分布和可选转写。数值只能描述声学现象，不能自动证明说话意图、音乐类型或情绪。

## 宿主复核

实际听取开头、中段、结尾、段落转折、异常点和代表片段，建立事实卡：

- 内容或音乐段落如何组织，转折由什么触发。
- 主讲人与听众的距离、语速、停顿、重音、重复和情绪推进。
- 人声、音乐、环境声、拟音和静默的层级关系。
- 片头、正文、高潮、收束和片尾的声音功能。
- 哪些特征属于说话者、栏目、题材、录音环境或单期内容。

不要根据音高直接判断人物身份、性别、年龄或情绪。不要把 BPM 候选当作曲风结论。

## 画像专属字段

- 内容/音乐结构及时间比例。
- 语速、停顿长度和重音触发条件。
- 音高、响度和动态变化的相对关系。
- 声音层数量、前后景和进入/退出规则。
- 转场、静默、音效和口播的同步关系。
- 录音空间、混响、声像和后期处理。
- 内容变量、声音资产边界和不可复用元素。

聚合多个节目或作品后，必须区分说话者习惯、栏目模板、题材、嘉宾、录音环境和单期制作选择。单条音频只能形成本期配方。

## 再生成边界

宿主只有文本生成能力时，交付旁白/播客脚本、声音时间表和制作规范。宿主确有音频生成或编辑能力时才能生成候选音频，并必须重新分析声学证据和语义结构，填写 `evaluation.json`。不得声称克隆具体人物声音，也不得把音色相近当作内容结构相同。
