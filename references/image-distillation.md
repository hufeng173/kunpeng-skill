# 图片、品牌与视觉蒸馏

## 范围

处理单图、海报、封面、摄影系列、插画、品牌资产、产品截图和视觉体系。界面截图只能证明可见状态；涉及任务流、交互或响应式行为时还必须使用 `ui-interaction.md` 和宿主采集证据。

单图形成画面配方，不能证明完整品牌或创作者风格。多个裁切/尺寸版本也不能冒充多个独立样本。

## 本地证据

```bash
python scripts/kunpeng.py probe --profile image
python scripts/kunpeng.py images <图片或目录> --output <证据目录>
```

先读 `manifest.json`、`collection-analysis.json` 和 `contact-sheet.jpg`，再查看每张原图及其 `analysis.json`。脚本提供尺寸、色彩、亮度、边缘、重心、对称、留白代理值和 OCR；这些不能自动识别主体、真实光源、字体名称、材质或设计意图。

## 来源清理

- 用文件指纹和视觉检查识别重复图、裁切、压缩和带水印版本。
- 区分主视觉、过程稿、模板、社交尺寸适配和异常图。
- 记录平台、尺寸、用途、时间和系列；不要把媒介约束当风格。
- 品牌标志、角色、字体授权和专属插画单独标为受保护资产。

## 语义事实卡

逐项检查：

- **内容与功能**：主体、动作、场景、信息目标、观看距离和使用位置。
- **构图**：画幅、视角、网格、主体区域、层级、留白、裁切、视觉重心和动线。
- **成像**：焦段感、透视、景深、曝光、主辅光、阴影、反射、颗粒和后期。
- **色彩**：背景、主体、强调、文字和状态色的角色、比例、对比与变化条件。
- **文字与图形**：字体类别、字重/字号比例、行距、对齐、形状、圆角、描边、图标和装饰母题。
- **材质与空间**：表面、纹理、真实/合成程度、前中后景和遮挡关系。
- **系统性**：哪些跨样本稳定，哪些由主题、活动、尺寸或某一模板决定。

每条规律写成关系和触发条件，例如“当画面只有一个主信息时，主体占中部约一半并用高明度强调色与暗背景分离”，而不是“高级、简约”。

## 视觉画像与生成包

把自动 draft 改成媒介专属契约：画布/尺寸、网格和区域比例；主体数量、姿态、视角与裁切；空间和镜头感；光线、色彩角色与材质；文字层级；后期；跨尺寸适配；内容变量；受保护资产；Do/Don't；可观测验收项。

- `faithful`：仅在授权范围内固定主体、位置、文字、颜色、光线和材质关系。
- `transfer`：固定视觉机制，替换主体、场景、文案和专属资产；不能复制 Logo、角色或整套品牌身份。

## 应用和验收

先生成布局/构图规格，再生成候选。对候选运行同一图片分析器并实际查看原图，分别验收内容正确、构图层级、颜色角色、光线材质、文字可读性、品牌边界和技术瑕疵。指标接近但主体关系或信息目标不同必须失败。
