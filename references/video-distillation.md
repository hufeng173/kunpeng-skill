# 视频蒸馏

## 目标和边界

单条视频只能形成该作品的“制作配方”；同一创作者的稳定风格必须由多个独立视频支持。切镜、像素差或一张中点帧不能证明推、拉、摇、移、跟拍或环绕，所有运动候选都要结合连续帧和原片复核。

未说明时按 `transfer` 处理：迁移叙事、镜头、剪辑、声音和图文协同机制，替换主题、人物、场景、台词和专属资产。

## 本地证据

```bash
python scripts/kunpeng.py probe --profile video
python scripts/kunpeng.py video <视频或目录> --output <证据目录> --frames-per-scene 5 --motion-sample-fps 4
```

本地模型已准备且要求断网时加 `--whisper-model <目录> --offline`。普通任务不用 `--strict`，缺一项时继续其余阶段。

先读 `manifest.json` 和 `collection-analysis.json`，再按需读取每项：

- `probe.json`：时长、画幅、帧率、音轨和字幕流。
- `subtitles/`、`transcript.json`：字幕、ASR 和时间戳。
- `scenes.json`：镜头边界或明确标记的固定间隔降级。
- `keyframes/`：每镜头开头、四分之一、中段、四分之三、结尾等多阶段样本与联系表。
- `motion-analysis.json`：基于特征点、RANSAC 与仿射变化的全局运动候选、残差和限制。
- `ocr.json`：采样画面文字及时间区间。
- `audio-analysis.json`：节拍候选、响度、停顿、频谱和时间包络。
- `timeline.json`：镜头、讲话和画面文字的统一时间线。

运动候选只能缩小复核范围：主体运动、视差、变焦、稳定裁切、灯光、转场和特效都可能干扰估计。

## 逐项语义复核

1. 从第一帧到最后一帧划分钩子、发展、转折、高潮、行动和收束，记录时长比例。
2. 每个关键镜头同时查看起、中、末连续阶段，记录景别、机位、焦段感、景深、构图和主体轨迹。
3. 区分相机全局运动、人物/物体局部运动、数字缩放、稳定器裁切、剪切和转场。
4. 记录运动方向、幅度、速度曲线、开始/停止触发及其叙事功能；无法判断时保留候选集合。
5. 对齐对白/旁白、字幕、屏幕文字、音乐、音效、静默、节拍和剪辑点。
6. 检查场景、人物、道具、视线、屏幕方向、光线和色彩的跨镜头连续性。
7. 批量视频逐条建卡后再聚类，区分创作者风格、栏目模板、题材要求、平台时长和单条创意。

## 视频画像与生成包

画像至少包含：

- 观看场景、受众和目标效果。
- 叙事段及归一化时长、镜头数量和信息密度。
- 景别、机位、构图、相机运动、主体动作及二者关系。
- 镜头长度分布、切点触发、转场、速度变化和节奏同步。
- 光线、色彩、材质、调色、字幕、图形和特效规则。
- 旁白/对白、音乐、环境声、拟音和静默的层级与进入/退出规则。
- 人物、场景、道具、屏幕方向和声音的连续性约束。
- 内容变量、异常样本、禁止项、失败模式和适用边界。

没有可调用的视频生成器时，完整交付是模型无关的逐镜表、资产清单、首尾状态、声音时间表、提示适配说明和验收表，不得声称已生成成片。宿主实际拥有 Runway、Seedance 或其他工具时，再按该工具当前支持的控制项映射；不支持的约束转为验收项。

## 新主题复刻闭环

1. 把新主题映射为叙事段和信息节拍，不机械替换原视频名词。
2. 先锁定全片结构、逐镜职责和镜头连接，再写各镜头提示或拍摄说明。
3. 为每镜定义起始状态、结束状态、主体动作、相机动作、声音和连续性锚点。
4. 逐镜生成/拍摄并拼接；失败镜头只按失败维度重做。
5. 对候选再次运行视频分析，逐镜比较时间、运动方向/幅度、主体关系、剪辑点和音画同步。
6. 填写 `evaluation.json`；硬约束或关键连续性失败时不得通过。

忠实重建需要逐镜绝对时间；同机制新内容可以使用归一化比例，但仍要给镜头数、节奏和连接规则。
