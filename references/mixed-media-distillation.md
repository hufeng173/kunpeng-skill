# 混合素材蒸馏

## 何时使用

当代码、网站、UI、图片、视频、音频、文档等共同描述同一项目、创作者、品牌、课程或方法时使用。无共同对象或共同目标的素材不要强行合并。

## 先分后合

1. 每种素材先运行自己的确定性分析器。
2. 可合并证据清单，保留各项原始类型：

```bash
python scripts/kunpeng.py merge <manifest-1.json> <manifest-2.json> --output <混合证据目录>
```

3. 直接把多个原始 manifest 一次交给复核准备器，使每项保持自己的媒介维度：

```bash
python scripts/kunpeng.py prepare-review <manifest-1.json> <manifest-2.json> --output <混合复核目录>
```

4. 在对应来源卡中使用相同 pattern key 记录跨媒体规律，并在 evidence 中定位其他来源；不要额外创建没有 manifest 来源 ID 的虚假卡。
5. 最后生成统一画像和必要的媒介专属子画像。运行质量门时登记原始 manifests，或只登记已合并 manifest，二者不要重复登记。

## 跨媒体关系

重点判断：

- 代码能力与页面承诺是否一致。
- UI 状态、文案、品牌视觉和用户路径如何配合。
- 视频画面、旁白、字幕、音乐和产品功能如何同步。
- 课程讲解、示例项目和文档说明是否相互支持。
- 同一规律是否在多个媒介出现，还是只由某种媒介限制造成。
- 来源之间存在什么矛盾、时间差、版本差和权限边界。

## 合并规则

- 保留原始 `source_id`、媒介类型和证据定位。
- 跨媒体规律至少指出两个不同来源之间的关系。
- 冲突无法解释时保留冲突，不选择更顺耳的一方。
- 统一画像保存共同目标、共享机制和依赖；媒介参数留在子画像中。
- 新 idea 的完整生成包按实际可用工具拆分为代码、页面、视觉、文案、音视频等产物，并用统一验收表检查协同关系。
