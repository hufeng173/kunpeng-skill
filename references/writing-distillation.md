# 文章与表达蒸馏

## 目标

从同一作者、栏目或内容体系的多篇文本中提取可迁移的组织与表达机制，用于新主题写作。它不是保存句长和标点统计，也不是复用原文长句。书籍/课程的知识方法另读 `knowledge-course-distillation.md`；需要时分别建立“知识画像”和“表达画像”。

## 建立语料

```bash
python scripts/kunpeng.py probe --profile document
python scripts/kunpeng.py documents <文档或目录> --output <证据目录>
```

先读 `manifest.json` 和 `corpus-analysis.json`：

- 标记精确重复、转载、同稿多格式和近重复版本，并为它们填写带理由的 excluded 卡。
- 识别固定页眉页脚、平台提示、广告模板和免责声明。
- 核对作者、栏目、时间、体裁、平台和是否有编辑/合作者。
- 极短通知、采访转录、客座文章等异常体裁单独分组。
- 保留一部分代表文本作为留出集，不参与画像归纳。

没有固定篇数能保证学会风格。样本要覆盖不同主题和时期；单篇只能形成该文配方，少量同题文章很容易把主题词误当文风。

## 阅读与事实卡

先看每篇开头、中段、结尾和结构索引，再按问题读取必要分块。填写事实卡时至少检查：

- **任务结构**：开头钩子、问题提出、背景、论点、证据、案例、反驳、转折、行动建议和结尾如何排序。
- **思维动作**：定义、拆分、归因、比较、类比、设问、预判异议、反证、升维和收束在什么条件触发。
- **叙事距离**：作者位置、读者称呼、确定性、权威来源、自我暴露和评价尺度。
- **情绪曲线**：紧张、共鸣、幽默、愤怒、希望等如何进入、升级和释放；不能只贴情绪标签。
- **幽默与修辞机制**：铺垫、错位、反差、重复、比喻、引用和金句承担什么功能。
- **句法与节奏**：句长分布、长短句切换、段落密度、留白、小标题、列表和标点与段落职责的关系。
- **词汇角色**：功能词、连接词、动词强度、术语解释、口语程度、抽象/具体转换和禁用表达。
- **边界**：哪些只属于题材、热点、平台格式、广告合作或某一时期。

自动 `style_metrics` 是证据之一，不能单独证明论证、幽默、价值判断或情绪机制。关键规律必须定位到真实段落，并优先由不同主题文章共同支持。

## 作者画像

运行 `prepare-review` 和 `build-profile` 后，把通用契约改为写作专用契约：

- 读者、目的、平台、篇幅和事实边界。
- 篇章阶段、各阶段职责、比例和转场触发。
- 论证动作、证据类型、反驳方式和观点确定性。
- 叙述视角、读者距离、语气、情绪推进和幽默机制。
- 句法、段落、词汇、格式和修辞的条件化规则。
- 主题事实、案例、人名、数据和专属表达等内容变量。
- 禁止复用的长句、故事、口头禅组合和来源专属事实。
- 分阶段验收项以及事实核验、原创性和可读性要求。

同一作者在不同栏目或时期存在明显分支时，保留条件画像，不平均成一种虚假的“万能口吻”。

## 新主题生成

1. 单独建立新主题事实包，标明已核实事实、未知和不得编造项。
2. 根据画像生成文章目标、大纲、段落职责和证据需求。
3. 先写内容正确的初稿，再按画像做结构和表达重写。
4. 检查事实、引用、逻辑跳跃、重复和来源专属表达。
5. 用同一文档分析器复测候选，再做语义维度验收。

不要只给模型一段“模仿某作者”的提示词；加载当前画像、事实包和少量短代表片段即可，不重新塞入全部语料。

## 验收

`evaluation.json` 至少分别检查：事实正确与主题覆盖、篇章职责与论证动作、语气与读者距离、句段节奏与词汇角色、修辞/情绪机制、原创性和禁用表达。表面统计相近但叙事目的不同必须失败。

优先用留出文章校准画像：先隐藏作者标签，让评审比较候选与目标作者、非目标作者的机制接近程度；这只能提供证据，不能把一次主观判断写成准确率保证。
