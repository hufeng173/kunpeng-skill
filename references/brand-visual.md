# 品牌与视觉蒸馏

## 目标

把图片、视频、网站、App、品牌资料或混合素材中的视觉判断转成设计师可继续使用的规则。输出设计系统和适用边界，不输出风格形容词堆砌。

## 分析顺序

1. **品牌基础**：目标受众、使用情境、品牌定位、人格、情绪、语气和信任方式。
2. **内容策略**：信息优先级、叙事顺序、主张与证据如何配合。
3. **构图系统**：网格、对齐、比例、留白、密度、焦点、节奏和响应式变化。
4. **字体系统**：字体类别、层级、字号、字重、行高、段宽和数字处理。无法确认字体时只描述类别。
5. **色彩系统**：主色、中性色、功能色、背景、对比度、色彩占比和使用条件。
6. **形状与材质**：圆角、描边、阴影、透明、纹理、光照、层叠和空间关系。
7. **图像语言**：摄影对象、镜头、裁切、景深、插画、图标、纹理和重复视觉母题。
8. **动效语言**：触发、目的、频率、方向、时长、缓动、延迟、滚动关系和降级方式。
9. **跨媒介一致性**：网页、移动端、视频、海报、社交素材和产品界面如何共享同一识别系统。

## 频率与证据

- 三个及以上独立样本稳定重复：视为系统规则。
- 两个样本重复：视为候选模式，需要更多验证。
- 单次出现：视为个例，不上升为品牌原则。
- 样本少于三个：使用“全部、部分、单个”描述，不伪造百分比。
- 同时寻找反例，判断规则是全局规范、特定活动变化还是内容限制。

## 蒸馏卡

内部按以下结构形成候选，不必逐卡暴露给最终使用者：

```text
可见证据 → 视觉目的 → 可执行规则 → 推荐参数 → 适用场景 → 不适用场景
```

只有同时满足以下条件才进入最终设计原则：

1. 有多个真实画面或交互状态支撑。
2. 能解释为什么这样设计，而不只是描述长相。
3. 能迁移到新内容或新载体。
4. 能写出参数、优先级或明确操作。
5. 能说明代价、边界或反例。

## 建议输出

按任务需要选择，不硬凑全部章节：

- 品牌核心：受众、定位、人格、情绪和语气。
- 视觉总原则：3–7 条最稳定的判断。
- 版式系统：网格、层级、留白和密度。
- 字体与色彩：角色、搭配和使用规则。
- 图像与资产：摄影、插画、图标、纹理和母题。
- 动效系统：哪些地方动、为何动、怎样动、何时静止。
- 设计 Token：可确认或合理建议的颜色、间距、尺寸、圆角、描边和时长。
- Do/Don't：正确做法、常见误用和品牌稀释风险。
- 跨媒介迁移：网页、App、视频和营销素材的适配方法。

## 产品规划中的使用

把蒸馏结果转换成目标产品自己的视觉方向。可以给出具体 Token、版式和动效建议，但不得列出参考项目、来源文件或“借鉴自”说明。

## 质量边界

- 不复制 Logo、商标、角色、独特插画或可识别整套品牌资产。
- 不把暂时流行的效果当作品牌本质。
- 不为追求视觉冲击牺牲可读性、加载、可访问性和核心任务效率。
- 不猜测未知字体、设计工具或实现技术。
- 不把视频中的镜头语言直接当作产品 UI 规范，先判断媒介差异。
