# 再生成与迁移规范

## 定位

最终产物不是一段万能“反向提示词”，而是模型无关、可参数化、可验收的生成契约。宿主有对应生成能力时可以直接生成候选；没有时交付完整制作包，不虚构调用结果。

## 两种模式

- `faithful`：授权范围内重建当前对象，固定内容与结构中的必要部分。
- `transfer`：迁移组织、表现和决策机制，替换主题、事实、主体、案例、场景、文案和专属资产。

未说明时选择 `transfer`。画像和 `evaluation.json` 必须使用同一模式。

## 通用契约

`generation_contract` 至少包含：

```json
{
  "review_status": "reviewed",
  "mode": "faithful|transfer",
  "medium": "实际输出媒介",
  "target_effect": "受众要理解、感受或完成什么",
  "invariants": ["必须保留的机制、结构和关系"],
  "variables": ["本任务可替换的内容"],
  "sequence": ["从全局到局部的生成步骤"],
  "negative_constraints": ["禁止内容和常见失败"],
  "acceptance": ["可观察、可定位、可判定的通过条件"]
}
```

规则优先写绝对值、范围、比例、顺序、数量、方向和触发条件；无法精确时写相对关系并注明依据。每条形容词都落到可见、可听、可读或可执行的参数。

## 媒介补充

### 代码、产品和工作流

输入/输出、角色与权限、模块边界、状态机、数据流、外部依赖、错误恢复、性能/安全约束、测试和完成定义。

### 网站、App、UI 和动效

信息架构、关键路径、布局与组件关系、全状态表、交互前后态、动效时长/缓动/触发、响应式、键盘/触控/无障碍和错误恢复。

### 图片与品牌

画布、网格、主体/文字区域、视角、裁切、空间、光线、色彩角色、材质、字体层级、后期、跨尺寸适配和受保护资产替换。

### 视频

总时长/画幅、叙事段、逐镜表、起止状态、景别/机位、相机与主体运动、转场、连续性、调色、字幕/图形、对白/旁白、音乐/音效和节拍点。

### 音频

段落比例、语速/停顿/重音、响度和动态关系、声音层、进入/退出、声像/空间、音乐/音效/静默和文字脚本。

### 文章与知识内容

读者/目的、事实边界、篇幅、段落职责、论证或教学动作、叙述距离、情绪/修辞、句段节奏、词汇角色、练习/反馈和原创性边界。

## 工具适配

1. 只映射工具当前实际支持的字段，不改变源契约。
2. 参考图、首尾帧、时间轴、结构化提示、代码模板等作为适配层保存。
3. 工具不支持的控制项转为验收条件，不假装已经受控。
4. 记录可确认的模型/工具版本、随机种子、参考权重和参数；未知不编造。
5. 生成后分析候选本身，提示词完整不等于结果通过。

## 复测与评价

候选用来源相同的解析器和语义维度复测。`evaluation.json` 必须指向已复核 profile、当前 workflow objective、注册的 candidate 路径以及实际存在的候选证据产物。

至少分三层：

1. **硬约束**：格式、尺寸、时长/篇幅、数量、必需对象、事实和权限。
2. **机制结构**：任务流、构图、时间轴、段落职责、运动、色彩角色、声音或论证关系。
3. **语义质量**：目标正确、连续自然、可读可用、无明显伪影/错误文字，并遵守原创与专属资产边界。

确定性 `compare` 分数只能作为诊断信号，不能单独证明风格、意义或质量相同。
