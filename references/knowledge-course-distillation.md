# 文档、书籍与课程蒸馏

## 目标

提取知识结构、决策方法、教学顺序和适用边界，而不是生成章节摘要合集。文章表达风格使用 `writing-distillation.md`；需要同时提取知识和文风时分别建事实卡，再在画像中标明两类规律。

## 证据建立

```bash
python scripts/kunpeng.py documents <文档、书籍或课程资料> --output <证据目录>
python scripts/kunpeng.py prepare-review <证据目录/manifest.json> --output <复核目录>
```

先读取目录、全局概览、开头、中段和结尾，再沿章节、课次或自然单元深读。每个分块必须携带同一全局问题，避免把局部建议误当成全书结论。

## 事实卡维度

- 核心问题、目标受众和预备知识。
- 概念、原则、框架及依赖关系。
- 论证链、证据类型、案例和反例。
- 教学顺序、难度曲线、练习、反馈和考核。
- 决策触发条件、参数、代价和失败模式。
- 来源中的事实、作者主张、推断和未验证假设。
- 跨章节稳定方法、阶段限定方法和冲突观点。

## 画像和应用

画像应能回答“遇到什么情况采用什么方法、为什么、如何执行、如何判断有效、何时停止”。应用到新领域时：

1. 映射新领域对象与原方法角色，不机械替换名词。
2. 检查前提、成本、数据和平台是否仍成立。
3. 保留无法迁移的差异和冲突。
4. 生成新的教学方案、决策流程或产品方法卡。
5. 使用正例、诱饵、边界、冲突和跨领域迁移题验收。
